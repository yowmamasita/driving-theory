# driving-theory

All of TÜV and DEKRA German driving theory exam questions and answers in English

## Question Banks

- [English Questions](./driving_theory_questions.md) - Complete set of driving theory questions in English
- [German Questions](./driving_theory_questions_de.md) - Complete set of driving theory questions in German (Deutsch)
- [English Questions, class B only](./driving_theory_questions_b.md) - The 1592 questions in the car (class B) pool
- [German Questions, class B only](./driving_theory_questions_de_b.md) - Same pool in German

Every question has a `licenses` field with the classes it belongs to, as listed on clickclickdrive.de (for example `["A", "A1", "A2", "B", "A80"]`). The class B files hold every part 1 question (ids `1.x`, the Grundstoff asked in every class) plus the part 2 questions tagged `B`.
